# Events API

Простой REST API для управления событиями на **ASP.NET Core Web API** (.NET 10).
Данные о событиях хранятся в памяти приложения (in-memory), поэтому при перезапуске сервиса они очищаются.

## Требования

- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) (или выше)

## Запуск проекта

```bash
dotnet build
dotnet run
```

После запуска API будет доступен по адресам (см. `Properties/launchSettings.json`):

- HTTP: `http://localhost:5238`
- HTTPS: `https://localhost:7118`

Swagger UI: http://localhost:5238/swagger (или https://localhost:7118/swagger)

## Структура проекта

```
├── Controllers/          # REST-контроллеры
```

## REST API

### GET /events

Возвращает список всех событий.

**Ответ:** `200 OK`

```json
[
  {
    "id": "3f6b3d1a-6a1e-4b7f-9a2c-5e1c2d3c4d5e",
    "title": "Название",
    "description": "Описание",
    "startAt": "2026-01-15T10:00:00Z",
    "endAt": "2026-01-15T18:00:00Z"
  }
]
```

### GET /events/{id}

Возвращает событие по идентификатору.

**Ответ:**
- `200 OK` — событие найдено
- `404 Not Found` — событие не найдено

### POST /events

Создаёт новое событие. Идентификатор генерируется автоматически.

**Тело запроса:**

```json
{
  "title": "Название",
  "description": "Описание",
  "startAt": "2026-01-15T10:00:00Z",
  "endAt": "2026-01-15T18:00:00Z"
}
```

**Ответ:**
- `201 Created` — событие создано, в теле — созданное событие
- `400 Bad Request` — нарушена валидация

### PUT /events/{id}

Обновляет событие целиком.

**Тело запроса:** то же, что и для `POST /events`.

**Ответ:**
- `200 OK` — событие обновлено
- `400 Bad Request` — нарушена валидация
- `404 Not Found` — событие не найдено

### DELETE /events/{id}

Удаляет событие.

**Ответ:**
- `204 No Content` — событие удалено
- `404 Not Found` — событие не найдено

## Валидация входных данных

- `title` — обязательное поле;
- `startAt` — обязательное поле;
- `endAt` — обязательное поле;
- `endAt` должен быть позже `startAt`;
- `description` — опциональное поле.

При нарушении валидации сервис возвращает `400 Bad Request` с описанием ошибок.

## Поля модели Event

| Поле          | Тип      | Обязательное | Описание                  |
|---------------|----------|--------------|---------------------------|
| `id`          | Guid     | да           | Идентификатор события     |
| `title`       | string   | да           | Название события          |
| `description` | string?  | нет          | Описание события          |
| `startAt`     | DateTime | да           | Дата и время начала       |
| `endAt`       | DateTime | да           | Дата и время окончания    |
